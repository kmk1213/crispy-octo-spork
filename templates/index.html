01 · 상품 후보 찾기

네이버 자동 조회에는 서버 API 키가 필요합니다. 나머지 쇼핑몰은 검색 링크와 직접 입력·CSV를 지원합니다.

직접 상품 추가 / CSV 형식

동일 모델·용량·수량·옵션을 확인한 상품에만 같은 그룹명을 입력하세요. 그룹별 사입 합계 1~3위를 표시합니다.

UTF-8 CSV 열: title,source,price,shipping,group,url (title, price 필수)

02 · 판매가와 비용 설정

수수료·세금·반품 충당액은 매출 기준 추정 비율입니다. 판매 국가·카테고리·세금 조건에 맞춰 수정하세요. 사입가와 비용은 원화로 입력하고, 해외 사입가는 먼저 원화로 환산하세요.

03 · 가격 비교와 예상 수익

조회·입력한 후보 안의 가격 비교입니다. 배송비·옵션·재고는 구매 전 확인하세요. 같은 판매가를 적용하므로 한 번에 동일 판매 상품 후보를 비교하세요.

가격순위상품 / 그룹판매처사입 합계전체 비용예상 순이익수익률마진율목표

검색하거나 상품을 추가하면 분석 결과가 나타납니다.

04 · 필리핀·베트남 판매 플랫폼 비교

쇼피와 Lazada의 판매 시나리오를 상품 그룹별로 추가하세요. 시세와 비용을 직접 확인해 입력합니다. 아래 판매가·환율·비율·발송비·기타비가 위의 공통 설정을 대체하며, 사입 배송료·포장비·목표 수익률은 공통 설정을 사용합니다.

추천 1~3위는 서로 다른 상품 그룹입니다. 같은 상품의 여러 사입처·판매 시장 중 선택한 기준이 가장 좋은 조합을 추천합니다. 실제 수요·판매량을 확인한 인기 상품 추천은 아닙니다. 동일상품·시세 확인 및 목표 수익률을 충족해야 순위에 포함됩니다.

추천 순위상품 / 그룹사입처국가 / 판매 플랫폼판매가전체비용순이익수익률시세 확인

세금 충당액은 실제 부가세·소득세·관세 정산이 아닙니다. 확정된 비용과 환율을 적용해 판단하세요. 브라우저를 새로 열면 목록이 초기화됩니다.
