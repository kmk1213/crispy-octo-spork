# 사입 레이더

사입 후보의 가격·배송비 비교, 예상 수익 계산, XLSX 내보내기를 제공하는 한국어 로컬 웹 도구입니다.

## PC에서 화면 열기

GitHub 저장소에서 **Code → Download ZIP**을 선택하거나 [ZIP 다운로드](https://github.com/kmk1213/crispy-octo-spork/archive/refs/heads/main.zip)를 사용하세요. 다운로드한 ZIP 전체를 압축 해제한 뒤 아래 실행 파일을 사용합니다. ZIP 안에서 실행 파일만 열면 필요한 소스 파일을 찾지 못합니다.

현재 Codex 클라우드 온보딩 화면에는 이 로컬 웹 서버를 여는 앱 미리보기 경로가 없습니다. 내부 서버 테스트 성공은 ChatGPT·Codex의 화면 열기 버튼 정상 동작을 의미하지 않습니다. 외부 웹 배포는 아직 하지 않았습니다.

배포용 ZIP을 PC에서 압축 해제한 뒤 실행할 수 있습니다. Python 3.10 이상과 처음 의존성 설치 시 인터넷 연결이 필요합니다.

- Windows: `start-windows.bat`를 실행합니다. Python이 없으면 먼저 설치합니다.
- macOS·Linux: 압축을 푼 폴더에서 `sh start-mac-linux.sh`를 실행합니다.
- 실행기가 의존성을 설치하고 사용 가능한 로컬 포트에서 서버를 시작한 뒤 PC 브라우저를 엽니다. 터미널 창을 닫으면 서버가 종료됩니다.
- API 키가 없어도 직접 입력·CSV·계산·엑셀 저장을 사용할 수 있습니다. 네이버 자동 조회에는 별도 키가 필요합니다.

Linux의 새 가상환경에서 설치와 첫 화면 응답을 검증했습니다. Windows 실행기는 코드 검토를 마쳤으며 실제 Windows 실행은 아직 검증하지 않았습니다.

## 실행

```bash
cd /workspace/crispy-octo-spork
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

기본 바인딩은 127.0.0.1:8000입니다. 개발용 로컬 서버이며 공개 서비스 배포용 서버가 아닙니다.

## 사용 흐름

1. 키워드를 검색합니다. 네이버 API 키가 없으면 플랫폼별 검색 링크를 제공합니다.
2. 상품 정보를 직접 입력하거나 UTF-8 CSV를 가져옵니다. 필수 열은 `title,price`이며 선택 열은 `source,shipping,group,url`입니다.
3. 동일 모델·옵션·용량·수량인 후보에 같은 `group`을 부여합니다. 그룹 내 배송 포함 사입가 순위는 참고 정보입니다. 자동 동일상품 판별은 지원하지 않습니다.
4. 판매가·환율·수수료·세금 충당률·배송료 등을 입력합니다. 한 번의 분석에는 모든 후보에 같은 판매가를 적용합니다.
5. 엑셀 저장으로 분석 결과와 비용 설정을 받습니다. 브라우저 메모리만 사용하며 새로고침 시 목록은 초기화됩니다.

## 가격 검색 연동

- 네이버: `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` 환경 변수가 있으면 공식 쇼핑 검색 API로 키워드당 최저 표시 가격 순 100개까지 조회합니다. 서버 시작 전 안전한 환경 변수 주입 방식으로 설정하세요. 값을 소스나 채팅에 넣지 마세요. 실제 키를 사용한 원격 조회는 아직 검증하지 않았습니다.
- 쇼피·Lazada(필리핀·베트남), 올리브영, 다이소, 쿠팡: 검색 링크·직접 입력·CSV 가져오기만 지원합니다. 직접 가격 수집 커넥터는 미구현입니다. 플랫폼별 API 접근 권한과 수집 방식을 확인한 후 별도 연동이 필요합니다. 검색 링크의 실제 상품 결과는 검증하지 않았습니다.
- 표시 가격에는 배송비가 없을 수 있습니다. 재고·옵션·묶음 수량·쿠폰 조건을 확인하고 배송료를 입력해야 합니다. 결과는 입력·조회한 후보 범위의 비교이며 시장 전체 최저가나 판매 수요를 검증하지 않습니다.
- 네이버 검색 외 네트워크 요청을 서버에서 임의 상품 URL로 보내지 않습니다.

## 계산 기준 (상품 1개)

모든 사입가·비용은 원화입니다. 판매가만 판매 통화로 입력하고 환율을 적용합니다. 해외 사입가는 입력 전 원화로 환산하세요.

- 매출 = 판매가 × 환율
- 사입 합계 = 상품가 + 판매처 배송료 + 추가 사입 배송료
- 투입비용 = 사입 합계 + 고객 발송비 + 포장비 + 기타비
- 수수료·세금·반품 충당액 = 각각 매출 × 입력 비율
- 순이익 = 매출 − 투입비용 − 수수료 − 세금 충당액 − 반품 충당액
- 수익률 = 순이익 ÷ 투입비용 × 100
- 마진율 = 순이익 ÷ 매출 × 100
- 손익분기 매출 = 투입비용 ÷ (1 − 수수료율 − 세금률 − 반품률). 비율 합계가 100% 이상이면 계산 불가입니다.

기본 비율은 예시입니다. 세금은 실제 부가세·소득세 정산이 아닌 매출 비례 충당액이며 국가별 관세·플랫폼 정책을 자동 계산하지 않습니다. 관세 등 확정 비용은 기타비에 반영하세요. 배송비는 상품 1개에 배분된 금액을 입력하세요.

## 검증

```bash
.venv/bin/python -m unittest discover -s tests -v
```

비용 계산, 그룹별 순위, 잘못된 값 거부, CSV→XLSX 변환과 엑셀 수식 주입 방지, 네이버 응답 매핑(모의 응답)을 검증합니다.

## 필리핀·베트남 판매 비교 및 추천 TOP3

화면 04에서 상품 그룹에 대해 PH Shopee / PH Lazada / VN Shopee / VN Lazada 판매 시나리오를 등록합니다. 각 시나리오는 판매가(현지 통화), 환율(KRW/PHP 또는 KRW/VND), 수수료율, 세금 충당률, 반품 충당률, 고객 발송·국제 배송비, 기타비를 필수로 받습니다. 해당 비용이 없다면 0을 입력합니다. 임의의 현행 수수료율·실시간 환율을 제공하지 않습니다. 공통 설정의 사입 배송료·포장비·목표 수익률을 함께 사용합니다.

판매 시나리오와 동일한 그룹의 모든 사입 후보를 비교합니다. 따라서 서로 다른 상품도 각각 다른 판매가를 적용할 수 있습니다. 동일 모델·수량·옵션 및 시세를 직접 확인한 시나리오만 체크박스를 선택하세요. 시세가 미확인되거나 적자 또는 목표 수익률 미달인 상품은 TOP3에서 제외합니다. 상품별 가장 좋은 조합을 선택하여 서로 다른 상품 그룹 최대 3개를 추천합니다. 순이익순(기본) 또는 수익률순을 선택할 수 있습니다. 조건 충족 상품이 3개 미만이면 있는 만큼만 표시합니다.

이 순위는 입력한 가격과 비용에 따른 예상 수익 비교이며, 수요·판매량·실시간 최저가 또는 국가별 판매 적격성을 검증하지 않습니다. 자동 인기상품 발굴과 플랫폼 실시간 시세 수집은 미구현입니다. 판매 시세·수수료·배송비는 판매자 계정과 확인 가능한 자료를 통해 입력해야 합니다.

비교 엑셀에는 `추천 TOP3`, `국가 플랫폼 비교`, `계산 가정` 시트를 저장합니다. 판매처별 후보와 비용 가정을 함께 남겨 재검토할 수 있습니다.
