# MK커뮤니케이션 · 글로벌 소싱

MK커뮤니케이션의 국내 사입 후보 검색·가격 비교, 필리핀·베트남 판매 수익 분석, 추천 상품 TOP3와 XLSX 내보내기를 제공하는 한국어 웹사이트입니다. 회색·금색·흰색·노란색과 MK 메탈 로고를 사용합니다. **기본 사용 방식은 설치 없이 브라우저에서 사용하는 웹사이트입니다.** Python PC 실행기는 이전 버전용으로 남아 있습니다.

[PC 디자인 미리보기](docs/images/mk-desktop.png) · [모바일 디자인 미리보기](docs/images/mk-mobile.png). 화면의 상품·가격·수수료는 사용법 안내용 데모 데이터입니다. 디자인 반영과 실제 서버 게시·가격 수집 성공은 별도로 확인해야 합니다.

## 자동 상품·가격 수집 웹사이트

검색어를 입력하면 `/api/collect`가 국내 4곳과 필리핀·베트남 Shopee/Lazada의 공개 상품 가격을 조회하도록 연결되어 있습니다. `app.py`가 웹 화면과 수집 API를 같은 주소에서 제공합니다. 방문자 PC에는 Python을 설치할 필요가 없습니다.

**자동 수집은 GitHub Pages에서 실행할 수 없습니다.** [Render 서버 배포 설정](https://render.com/deploy?repo=https://github.com/kmk1213/crispy-octo-spork)을 사용하거나 Docker/Python 서버에 게시하세요. 배포 템플릿은 무료 플랜을 요청하며, 계정 로그인과 서비스 생성은 사용자가 호스팅 화면에서 진행해야 합니다. 현재 외부 호스팅이 생성되거나 자동 수집 사이트가 실제 게시된 상태는 아닙니다.

**실제 연동 검증은 미완료입니다.** 현재 환경의 원본 사이트 전 단계 프록시가 8곳 모두 `CONNECT 403`을 반환해 실제 가격은 0건입니다. 테스트의 상품 응답은 합성 표준 JSON-LD/모의 API 자료입니다. 공개 JSON-LD 상품 가격과 선택적 네이버 공식 API를 지원하지만, 각 쇼핑몰의 현재 페이지 구조를 검증한 전용 선택자는 없으므로 모든 사이트에서 추출이 된다고 보장할 수 없습니다. 자바스크립트 렌더링·로그인·접근 차단 화면은 수집 성공으로 처리하지 않습니다.

검색 결과에는 원본 상품명, 가격, KRW/PHP/VND 통화, 출처, 실제 조회 시각, 배송비 미확인을 표시합니다. 가격 범위의 최저 표시가는 `부터`로 표시하며, 특정 옵션 가격으로 계산에 자동 사용하지 않습니다. 국내 고정 가격은 사입가 입력에, 해외 고정 가격은 해당 시장 판매가 입력에 옮깁니다. 그룹·배송료·환율·수수료는 별도 확인해야 합니다.

자세한 배포·네트워크·검증 제한은 [자동 수집 배포 안내](docs/AUTOMATIC_COLLECTION.md)를 참고하세요. 네이버 키를 사용할 경우 서버의 비밀 환경 변수로만 설정하며 공개 HTML/JavaScript에는 넣지 않습니다.

## 웹사이트 게시

`web/`에 설치·서버가 필요 없는 사이트가 있습니다. 상품과 판매 시나리오, 비용 설정은 브라우저의 로컬 저장소에 보관하며 작업 백업 JSON을 내보내거나 복원할 수 있습니다. 외부 CDN이나 제3자 스크립트를 로드하지 않습니다.

웹사이트 파일은 `gh-pages` 브랜치로 게시합니다. GitHub 저장소 **Settings → Pages → Build and deployment**에서 다음과 같이 설정하세요.

1. Source: **Deploy from a branch**
2. Branch: **gh-pages**, 폴더: **/ (root)**
3. **Save**. GitHub가 빌드를 마치면 같은 화면에 접속 주소가 표시됩니다.

현재 세션에서는 GitHub REST API가 네트워크 정책으로 차단되어 Pages 활성 상태와 실제 공개 주소를 확인하지 못했습니다. 브랜치 업로드 성공만으로 사이트가 게시되었다고 간주하지 않습니다. 저장소·요금제에서 Pages가 지원되는지도 해당 설정 화면에서 확인할 수 있습니다.

정적 사이트에는 국내 사입 후보 입력·CSV 가져오기, 필리핀·베트남 Shopee/Lazada 판매 조건 비교, 순이익 또는 수익률순 TOP3, 실제 `.xlsx` 다운로드가 있습니다. 예시 버튼은 실제 가격이 아닌 데모 데이터를 사용합니다. GitHub Pages 버전은 자동 수집 서버 연결이 없음을 표시하고 쇼핑몰 검색 링크를 제공합니다. 자동 가격 조회는 위의 서버 배포 버전에서 요청합니다. 판매량 조회는 미연동입니다. API 비밀키를 공개 사이트에 넣으면 안 됩니다.

상품·비용은 원화, 해외 판매가는 PHP/VND로 입력하며 시나리오별 환율을 적용합니다. 세금은 충당 추정이며 실제 부가세·소득세·관세 정산을 대신하지 않습니다. 비교 엑셀은 최대 10,000개 조합을 저장합니다.

### 웹사이트 검증

```bash
node tests/test_web_core.cjs
node tests/test_web_xlsx.cjs
.venv/bin/python tests/check_web_xlsx.py
node tests/test_web_browser.cjs
```

브라우저 검증에는 Node 22 이상과 Chromium이 필요합니다. 입력·CSV 가져오기·시나리오 비교·추천 TOP3·실제 엑셀 다운로드·새로고침 후 복원·모바일 폭을 실제 Chromium에서 확인합니다. XLSX는 openpyxl로 독립 검증합니다.

## PC에서 화면 열기

GitHub 저장소에서 **Code → Download ZIP**을 선택하거나 [ZIP 다운로드](https://github.com/kmk1213/crispy-octo-spork/archive/refs/heads/main.zip)를 사용하세요. 다운로드한 ZIP 전체를 압축 해제한 뒤 아래 실행 파일을 사용합니다. ZIP 안에서 실행 파일만 열면 필요한 소스 파일을 찾지 못합니다.

현재 Codex 클라우드 온보딩 화면에는 이 로컬 웹 서버를 여는 앱 미리보기 경로가 없습니다. 내부 서버 테스트 성공은 ChatGPT·Codex의 화면 열기 버튼 정상 동작을 의미하지 않습니다. 외부 웹 배포는 아직 하지 않았습니다.

배포용 ZIP을 PC에서 압축 해제한 뒤 실행할 수 있습니다. Python 3.10 이상과 처음 의존성 설치 시 인터넷 연결이 필요합니다.

- Windows: `start-windows.bat`를 실행합니다. Python이 없으면 먼저 설치합니다.
- macOS·Linux: 압축을 푼 폴더에서 `sh start-mac-linux.sh`를 실행합니다.
- 실행기가 의존성을 설치하고 사용 가능한 로컬 포트에서 서버를 시작한 뒤 PC 브라우저를 엽니다. 터미널 창을 닫으면 서버가 종료됩니다.
- API 키가 없어도 직접 입력·CSV·계산·엑셀 저장을 사용할 수 있습니다. 네이버 자동 조회에는 별도 키가 필요합니다.

Linux의 새 가상환경에서 설치와 첫 화면 응답을 검증했습니다. Windows 실행기는 코드 검토를 마쳤으며 실제 Windows 실행은 아직 검증하지 않았습니다.

### 실행해도 화면이 안 뜰 때

- 이 파일은 Python 설치가 필요한 PC용 프로그램입니다. 휴대폰·태블릿에서 BAT나 Python 파일을 눌러 실행할 수 없습니다.
- Windows에서는 ZIP을 우클릭해 **모두 압축 풀기**를 먼저 하고, 풀린 폴더의 `start-windows.bat`를 실행하세요. `app.py`나 ZIP 안의 BAT만 더블클릭하지 마세요.
- 검은 창에 Python 관련 오류가 나오면 [Python 3.10 이상](https://www.python.org/downloads/)을 설치한 뒤 다시 실행하세요.
- 서버는 시작됐는데 브라우저가 열리지 않으면 실행 창의 수동 접속 주소를 브라우저 주소창에 입력하세요. 실행 창은 열어 두어야 합니다.
- 오류 문구가 나오면 해당 창의 내용을 확인해야 합니다. 실행 실패와 다운로드 실패는 원인이 다릅니다.

## 실행

```bash
cd /workspace/crispy-octo-spork
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

기본 바인딩은 127.0.0.1:8000입니다. 개발용 로컬 서버이며 공개 서비스 배포용 서버가 아닙니다.

## 사용 흐름

1. 키워드를 검색합니다. 네이버 API 키가 없으면 플랫폼별 검색 링크를 제공합니다.
2. 상품 정보를 직접 입력하거나 UTF-8 CSV를 가져옵니다. 필수 열은 `title,price`이며 선택 열은 `source,shipping,group,url`입니다.
3. 동일 모델·옵션·용량·수량인 후보에 같은 `group`을 부여합니다. 그룹 내 배송 포함 사입가 순위는 참고 정보입니다. 자동 동일상품 판별은 지원하지 않습니다.
4. 판매가·환율·수수료·세금 충당률·배송료 등을 입력합니다. 한 번의 분석에는 모든 후보에 같은 판매가를 적용합니다.
5. 엑셀 저장으로 분석 결과와 비용 설정을 받습니다. 브라우저 메모리만 사용하며 새로고침 시 목록은 초기화됩니다.

## 가격 검색 연동

- 네이버: `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` 환경 변수가 있으면 공식 쇼핑 검색 API로 키워드당 최저 표시 가격 순 100개까지 조회합니다. 서버 시작 전 안전한 환경 변수 주입 방식으로 설정하세요. 값을 소스나 채팅에 넣지 마세요. 실제 키를 사용한 원격 조회는 아직 검증하지 않았습니다.
- 쇼피·Lazada(필리핀·베트남), 올리브영, 다이소, 쿠팡: 검색 링크·직접 입력·CSV 가져오기만 지원합니다. 직접 가격 수집 커넥터는 미구현입니다. 플랫폼별 API 접근 권한과 수집 방식을 확인한 후 별도 연동이 필요합니다. 검색 링크의 실제 상품 결과는 검증하지 않았습니다.
- 표시 가격에는 배송비가 없을 수 있습니다. 재고·옵션·묶음 수량·쿠폰 조건을 확인하고 배송료를 입력해야 합니다. 결과는 입력·조회한 후보 범위의 비교이며 시장 전체 최저가나 판매 수요를 검증하지 않습니다.
- 네이버 검색 외 네트워크 요청을 서버에서 임의 상품 URL로 보내지 않습니다.

## 계산 기준 (상품 1개)

모든 사입가·비용은 원화입니다. 판매가만 판매 통화로 입력하고 환율을 적용합니다. 해외 사입가는 입력 전 원화로 환산하세요.

- 매출 = 판매가 × 환율
- 사입 합계 = 상품가 + 판매처 배송료 + 추가 사입 배송료
- 투입비용 = 사입 합계 + 고객 발송비 + 포장비 + 기타비
- 수수료·세금·반품 충당액 = 각각 매출 × 입력 비율
- 순이익 = 매출 − 투입비용 − 수수료 − 세금 충당액 − 반품 충당액
- 수익률 = 순이익 ÷ 투입비용 × 100
- 마진율 = 순이익 ÷ 매출 × 100
- 손익분기 매출 = 투입비용 ÷ (1 − 수수료율 − 세금률 − 반품률). 비율 합계가 100% 이상이면 계산 불가입니다.

기본 비율은 예시입니다. 세금은 실제 부가세·소득세 정산이 아닌 매출 비례 충당액이며 국가별 관세·플랫폼 정책을 자동 계산하지 않습니다. 관세 등 확정 비용은 기타비에 반영하세요. 배송비는 상품 1개에 배분된 금액을 입력하세요.

## 검증

```bash
.venv/bin/python -m unittest discover -s tests -v
```

비용 계산, 그룹별 순위, 잘못된 값 거부, CSV→XLSX 변환과 엑셀 수식 주입 방지, 네이버 응답 매핑(모의 응답)을 검증합니다.

## 필리핀·베트남 판매 비교 및 추천 TOP3

화면 04에서 상품 그룹에 대해 PH Shopee / PH Lazada / VN Shopee / VN Lazada 판매 시나리오를 등록합니다. 각 시나리오는 판매가(현지 통화), 환율(KRW/PHP 또는 KRW/VND), 수수료율, 세금 충당률, 반품 충당률, 고객 발송·국제 배송비, 기타비를 필수로 받습니다. 해당 비용이 없다면 0을 입력합니다. 임의의 현행 수수료율·실시간 환율을 제공하지 않습니다. 공통 설정의 사입 배송료·포장비·목표 수익률을 함께 사용합니다.

판매 시나리오와 동일한 그룹의 모든 사입 후보를 비교합니다. 따라서 서로 다른 상품도 각각 다른 판매가를 적용할 수 있습니다. 동일 모델·수량·옵션 및 시세를 직접 확인한 시나리오만 체크박스를 선택하세요. 시세가 미확인되거나 적자 또는 목표 수익률 미달인 상품은 TOP3에서 제외합니다. 상품별 가장 좋은 조합을 선택하여 서로 다른 상품 그룹 최대 3개를 추천합니다. 순이익순(기본) 또는 수익률순을 선택할 수 있습니다. 조건 충족 상품이 3개 미만이면 있는 만큼만 표시합니다.

이 순위는 입력한 가격과 비용에 따른 예상 수익 비교이며, 수요·판매량·실시간 최저가 또는 국가별 판매 적격성을 검증하지 않습니다. 자동 인기상품 발굴과 플랫폼 실시간 시세 수집은 미구현입니다. 판매 시세·수수료·배송비는 판매자 계정과 확인 가능한 자료를 통해 입력해야 합니다.

비교 엑셀에는 `추천 TOP3`, `국가 플랫폼 비교`, `계산 가정` 시트를 저장합니다. 판매처별 후보와 비용 가정을 함께 남겨 재검토할 수 있습니다.
